acceptance of the requests. It does **not** measure clocks, power, temperature,

## Reproduce

Run `:patches:test` and the normal Android/catalog graph with GitHub Packages
access configured. The two focused classes are `PerformanceBoostPatchTest` and
`PatchCategoriesTest`. They require no proprietary APK or capture. For native
host checks, configure `extensions/performance-boost` with `GXR_BOOST_TESTS=ON`
and run CTest in an external build directory. Keep output under the repository's
`../builds/steamlink-patches/` root. For device verification, inspect the
`GxrPerformanceBoost` log tag while Steam Link starts an XR session.
